How this works, and how to check it yourself

  • Each report is an Arkiv entity on the Tiramisu testnet. This page reads them straight from Arkiv, not from our server.
  • A live cut is a 2-hour lease. Every “Still dark” from a neighbour renews it. If nobody renews it, it disappears from “Right now” by itself.
  • “Power's back” turns it into a read-only record kept for a year. Nobody, including us, can edit it. Only the relay wallet could delete it, and that would be visible on chain.
  • Your phone holds a device key that signs every action. Our relay pays the testnet fee and writes it. The signature is stored with the record, so anyone can check who said what.
